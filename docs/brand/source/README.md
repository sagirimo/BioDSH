# Geometry provenance

The approved mark is a native vector reconstruction of the earlier BioDSH wordmark direction. It is not claimed to be the exact recovered historical SVG. The retained starting contours are derived from Montserrat (see OFL.txt). D, H, the i dot, spacing and the connector were refined as vector geometry; no bitmap is embedded. `geometry.json` records the final path geometry. SVGs in ../brand are the approved masters and are directly editable in vector tools.
