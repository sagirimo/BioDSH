# BDSH 四格插件证据栈

用户选择的混合方向：保留概念板 F 的粗几何无衬线字感，把 D 的 `2×2` 四模块改成 E 的分层/透视视角，并在图标内使用 `B D / S H` 四个字母。

## 三个变体

- **A 深等距四格**：最像“从 E 的视角看 D”，叙事和立体层次最强；小尺寸需另做无字简化。
- **B 浅透视四格（推荐主案）**：仍保留证据栈深度，但 `B D / S H` 的阅读顺序最清楚。
- **C 正视证据栈（推荐小尺寸）**：四格正视，两个背层暗示 run bundle 与 grader；32–64 px 表现最稳。

图标中的 `BDSH` 是压缩 monogram；正式横向字标保持完整拼写 `BioDSH`。下一轮若确认 B，可将字母转为路径，并补齐 16/32/64/1024 px、单色版和横向字标。
