# BioDSH 标志方向探索（2026-08-31）

这一轮用于选方向，不替换 `desktop/branding/` 中已经提交的主图标。视觉上只借用 DeepSeek Harness 的克制深色、柔性流线、模块化和少量冷蓝信号色，不复制其鲸鱼、字标、Harness 胶囊或首屏构图。

## 六个方向

1. **A 证据节点 B（推荐）**：在现有“双弦 B”基础上加入插件接口与稀疏证据节点，兼顾品牌识别、产品差异和小尺寸表现。
2. **B 生命括号**：两个有机代码括号包住生命核心，最独立，也不把 BioDSH 局限为 DNA 工具。
3. **C 可追溯细胞**：不闭合细胞环与单一运行轨迹，强调样本、过程与证据；避免使用认证对勾。
4. **D 插件轨道**：核心保持稳定，能力由外部模块组合；最接近 Harness 的系统与生态语义。
5. **E 证据栈**：Skill、run bundle、grader 三层沿同一审计轨迹收敛，差异化强但生物语义较弱。
6. **F 字标接口**：为论文页眉、网站导航与联合品牌设计的横向字标方向，图标识别力最低但正式感最高。

## 选择建议

- 桌面应用图标优先：A、B。
- 论文与科研可信度优先：A、C、E。
- 强调插件生态优先：B、D。
- 下一轮只推进 2 个方向，每个方向补齐主图标、单色版、16 px 简化版、横向字标和浅/深背景测试。
