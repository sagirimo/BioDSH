# BioDSH 应用图标

为 BioDSH（医生与湿实验科学家用的生信智能体桌面版）设计的矢量应用图标，覆盖 Windows / macOS，气质定位为「专业、克制、现代」，对标 Apple / DeepSeek 的深色高级感。

## 概念

**主方向「双螺旋 B」**：把品牌首字母 B 作为主体字形，同时让 B 的两个「碗」由两条平行的弦线构成，暗示 DNA 双螺旋；右上角一枚四角「火花」代表 AI 智能体 / 一句话分析。整体只用一个图形符号，就同时讲清楚了「生信（B / 螺旋）」与「智能体（火花）」，且不依赖文字。

- B = BioDSH 首字母，字母形态作图形，小尺寸天然可辨识。
- 双弦线 + 横档 = DNA 碱基对，点出基因组 / 湿实验语境。
- 四角火花 = AI / agent / 插件，呼应「Everything is a plugin. 每一次分析，都是一句话」。

备选方向：
- `alt/plugin-hex.svg`：石墨黑 + 青绿高光，六边形分子骨架 + 六个顶点节点 + 中心芯片，直接讲「一切皆插件 / 分子 / 生态」。
- `alt/double-helix.svg`：双螺旋 X，最直白的基因组 / 生信符号。

## 配色

- 主图标：深蓝 → 靛紫渐变（`#4d6bfe → #6858f6 → #7c5cff`），延续现有主页；顶部叠加一层极淡的白色高光，形成 Apple 式圆角方玻璃感。
- 火花强调色：青绿 → 青（`#34d399 → #22d3ee`），给深色主色一个克制的科技点缀，也呼应「生信 + 插件」。
- 单色版：纯白图形、透明底，专用于深色标题栏 / 网站 logo。
- 备选方向二：石墨黑（`#1b2534 → #080d18`）+ 青绿高光，走「开发者 / 深度科技」气质。

## 为什么小尺寸可辨识

- 主体只有一个粗壮的字母 B，没有细小文字、没有照片、没有多层堆叠，16px 下仍能认出主形状。
- `icon-small.svg` 专为 16–32px 优化：去掉双弦线、横档和火花，笔画加粗到约 11%，两个「碗」的镂空（counter）刻意留大，32px 下不会糊成一团。
- 圆角方半径 22.5%（1024 下为 230），符合 macOS Big Sur 风格，图形居中并留足安全边距。

## 文件清单

| 文件 | 说明 |
| --- | --- |
| `icon.svg` | 1024×1024 主图标（圆角方 + 渐变 + B + 火花） |
| `icon-mono.svg` | 单色版（白色图形、透明底） |
| `icon-small.svg` | 16–32px 简化版（加粗、去细节） |
| `alt/plugin-hex.svg` | 备选方向：插件六边形 |
| `alt/double-helix.svg` | 备选方向：双螺旋 X |
| `preview.html` | 三款 SVG 在浅色 / 深色底、多尺寸并排验收 |
| `make_icons.py` | 生成 `out/` 下的 PNG / ICO / ICNS |

## 生成位图产物

```bash
python3 make_icons.py
```

脚本会依次尝试 `cairosvg` → Chrome 无头截图 → `librsvg`（ctypes 兜底），输出到 `out/`：

- `icon-{16,32,48,64,128,256,512,1024}.png`
- `icon.ico`（Windows，含 16/24/32/48/64/128/256）
- `icon.icns`（macOS，icp4/icp5/icp6 + ic07/ic08/ic09/ic10/ic11/ic12/ic13/ic14）

小尺寸（16/24/32）由 `icon-small.svg` 生成，其余由 `icon.svg` 生成。
